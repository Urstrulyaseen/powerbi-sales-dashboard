# 📊 Sales Dashboard (Power BI)

## 🚀 Project Overview

This project is an interactive sales dashboard built using Power BI. It provides insights into sales performance, profit trends, and customer behavior.

## 📌 Key Features

* KPI Cards (Total Sales, Profit, Orders, Margin)
* Sales Trend Analysis
* Category & Region Breakdown
* Interactive Filters (Slicers)
* Top Products Analysis

## 🛠 Tools Used

* Power BI
* SQL (optional)
* DAX (Data Analysis Expressions)

## 📈 Insights

* Electronics category generates highest revenue
* Profit shows fluctuation across months
* Certain regions outperform others consistently
